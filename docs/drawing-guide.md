# 描き方の手順書

LLMが `brute-paint` で、SNSのプロフィールアイコンを描くときの手順と決まり。人の描き手が自然にしていることを、コードで描くときにも守る。

## 守ること

- 描線と塗りは、すべてスクリプトのコードから出す。参考画像や、画像生成モデルの出力の画素を、描画に使わない。
- 参考画像は、見ることと、特徴を言葉や数値にすることにだけ使う。色は `brute-paint color` で数値にする。
- キャラの「変えない特徴」（`character.md`）を変えない。画風を変えること、デフォルメすることはよい。

## アイコンの前提

- 表示は48px（タイムライン）から400px（プロフィールページ）。円形に切り抜かれることがある。
- 主役は顔。顔が画面の大きな部分を占めるように、思い切って寄る。頭の上や肩が切れてよい。
- 円形に切り抜くと、四隅が消える。大事なもの（目、口、特徴的な飾り）は中央の円の中に置く。
- 48pxで潰れるものは描かない。細かい模様、細い線、小さな文字は、48pxで見て読めなければ消すか太くする。
- 背景は単色か、大きな形1〜2個。キャラの色と明度で差をつけ、48pxでも輪郭が背景に溶けないようにする。

## 工程

人の描き手と同じ順で、レイヤーを分けて描く。レイヤーの名前は、何の層かが分かる言葉にする（例：「髪（下塗り）」「髪の影」「線画」）。

1. 構図とラフ：顔の位置、大きさ、傾き、目線を決める。円の切り抜きと48pxで確かめる。
2. 下塗り：部位ごとに1色か、なめらかなグラデーションで塗る。部位ごとにレイヤーを分ける。
3. 影：下塗りにクリッピングした乗算のレイヤーに描く。影の色は灰色ではなく、色味のある少し暗い色にする（肌ならピンク寄り、髪なら髪色の暗い方）。
4. ハイライト：クリッピングしたスクリーンのレイヤーに描く。目と髪のつやに絞る。
5. 線画：入り抜きのある線で描く。線の色は真っ黒にせず、近くの色の暗い色にする。外側の輪郭は太く、内側の線は細く。
6. 顔の仕上げ：目、まつ毛、眉、口、頬の赤み。ここに一番時間を使う。
7. 確認：下の「確かめ方」。

## 力の配分

人の描き手は、顔に力を入れ、それ以外は手を抜く。全面を同じ密度で描くと、AIが描いたように見える。

| 部位 | 力の入れ方 |
|---|---|
| 目 | 一番力を入れる。虹彩のグラデーション、瞳孔、ハイライト2つ、上まつ毛の太い線、下まつ毛 |
| 顔の他の部分（輪郭、口、鼻、頬） | 丁寧に。ただし線は少なく |
| 前髪、顔の周りの髪 | 束の流れと影まで描く |
| 後ろ髪、頭頂 | 下塗り、大きな影、つや1本 |
| 服、体 | 下塗りと影1段。線は最小限 |
| 背景 | 単色か大きな形。描き込まない |

## AI感を避ける

次に当てはまったら、直す。

- 背景や服まで、顔と同じ密度で描き込んでいる。
- 全体に同じ質感（細かいノイズ、同じ光沢）が乗っている。
- 線が真っ黒で、太さが一定。
- 完全な左右対称。顔の向き、髪の分け目、目の形に、わずかな差をつける。
- 形の破綻（目の位置のずれ、首と顔のつながり、指の数）。左右反転（`form.png`）で見つけやすい。

## 確かめ方

`brute-paint render` が書く画像を見る。

- `sheet.png`：400px、円形の切り抜き、48pxの実寸、48pxの2倍。48pxでキャラと分かるか。円で大事なものが切れていないか。
- `ref_sheet.png`：参考画像と「変えない特徴」を並べたもの。特徴が変わっていないか。
- `form.png`：グレースケールと左右反転。明暗の差で形が読めるか。反転して形の狂いが見えないか。

毎回、何を直すかを1〜3個に絞ってから直す。一度に全部を直すと、良くなったのかどうか分からなくなる。

## 反復の決まり

- 直したら、前の回（`out/iter/` の1つ前）と比べる。良くなっていなければ、スクリプトを前の版に戻す。
- 3回続けて良くならなければ、止めて人に見せる。
- 1キャラにつき1日40回まで。
- 描き込みを増やすことは、良くすることではない。迷ったら減らす。
